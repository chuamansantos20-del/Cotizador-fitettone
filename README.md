# Cotizador Fitettone

Aplicación web sencilla para calcular cotizaciones de pedidos de Fitettone y preparar un mensaje para compartir por WhatsApp.

## Funcionalidades

- Ingreso de la cantidad de unidades.
- Cálculo automático combinando packs de 2 e unidades individuales.
- Selección del canal de entrega: recojo en punto de venta o delivery por coordinar.
- Resumen del pedido con opción para copiar el mensaje.

## Precios

- Unidad individual: S/ 35.00
- Pack de 2 unidades: S/ 65.00

El cálculo aplica la mayor cantidad posible de packs de 2 y cobra cualquier unidad restante al precio individual. El delivery no está incluido en el total y se coordina por separado.

## Cómo usar

1. Abre `index.html` en un navegador.
2. Ingresa la cantidad de unidades.
3. Selecciona el canal de entrega.
4. Haz clic en **Calcular pedido**.
5. Haz clic en **Copiar resumen** y pega el mensaje en WhatsApp.

## Tecnologías

- HTML
- CSS
- JavaScript

La aplicación es estática y funciona sin base de datos, servidor propio ni proceso de compilación.
